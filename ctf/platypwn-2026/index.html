Nimani o'rgandim

  1. Avval manba kodini o'qing. Web, Misc va Crypto flaglari skaner bilan emas, berilgan kodni diqqat bilan o'qish orqali topildi.
  2. Ma'lumot to'g'ri formatda kelgani uchungina unga ishonmang. Diceware'da ilova foydalanuvchi bergan manzildan kelgan har qanday to'g'ri PIR javobini qabul qilardi.
  3. Terminal skrinshotidan flag ko'chirganda 0 va O bir xil ko'rinadi. Matnni nusxalang, qayta yozmang.
  4. Joylashuvni topishda belgidagi har bir raqam muhim. Yo'l ko'rsatkichidagi balandlik rasm kulbada olinmaganini ko'rsatdi.
  5. Cheklovlarni hurmat qiling. Xaritada daqiqasiga 3 ta urinish berilgan edi, shuning uchun yuborishdan oldin xaritani tekshiring.

Что я понял

  1. Сначала читайте исходный код. Флаги Web, Misc и Crypto найдены внимательным чтением кода, а не сканированием.
  2. Не доверяйте данным только потому, что у них правильный формат. В Diceware приложение принимало любой корректный PIR-ответ с адреса, указанного пользователем.
  3. При копировании флага со скриншота терминала 0 и O выглядят одинаково. Копируйте текст, не перепечатывайте.
  4. В геолокации важна каждая цифра на знаке. Высота на указателе показала, что фото сделано не у хижины.
  5. Соблюдайте лимиты. Карта позволяла 3 попытки в минуту, поэтому проверяйте карту перед отправкой.

Lessons learned

  1. Read the source code first. The web, misc and crypto flags were all found by carefully reading the provided code, not by scanning.
  2. Don't trust data just because it has the right format. In Diceware the app accepted any well-formed PIR response from a user-supplied URL.
  3. When copying flags from a terminal screenshot, 0 and O look the same. Copy the text, never retype it.
  4. For geolocation, every number on a sign matters. The altitude on the signpost was the clue that the photo was not taken at the hut.
  5. Respect rate limits. The location picker allowed 3 tries per minute, so check the map before submitting.
